# Курсовая — правила проекта

## GitHub курсовой

Репозиторий курсовой: https://github.com/wtfus1n/kursovai.git

- Это основной и единственный GitHub курсовой работы.
- Вся работа над курсовой (текст, код, материалы) хранится в этом репозитории и отправляется (push) туда.
- Локальная папка проекта: `D:\cloude\coursework`, ветка `main`, remote `origin`.

## Правила

- Все файлы и папки называются на английском языке (содержимое может быть на русском).
